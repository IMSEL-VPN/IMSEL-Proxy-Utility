# Раздельное туннелирование (Split Tunneling)

Функция «Раздельное туннелирование» (Per-App VPN) позволяет выбрать, какие именно приложения на вашем устройстве будут использовать VPN-соединение. Это полезно, если некоторым приложениям (например, мобильным банкам) требуется прямой доступ в интернет без использования VPN.

## Как настроить?

1. Откройте боковое меню приложения.
2. Перейдите в раздел **«Раздельное туннелирование»**.
3. Вы увидите список всех установленных приложений:
   - Отметьте галочками те приложения, трафик которых должен маршрутизироваться через VPN.
   - Трафик всех остальных (неотмеченных) приложений пойдет напрямую, минуя VPN.
4. В верхнем правом углу есть переключатель системных приложений. Включите его, если вам нужно направить через VPN системный трафик устройства.

## Примечания
- По умолчанию (когда вы не настраивали этот раздел), через VPN направляется весь трафик устройства.
- Данная функция доступна только на платформе Android.
- Для работы этой функции приложение запрашивает разрешение на доступ к списку установленных приложений. Мы не собираем и не передаем этот список третьим лицам.
